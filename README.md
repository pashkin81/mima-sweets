# מי-מה מתוקים

האתר של המאפייה הביתית של מיקה ומתיו.

## מה יש בתיקייה

| קובץ | מה זה |
|---|---|
| `index.html` | האתר עצמו |
| `products.js` | רשימת המאפים: שמות, מחירים, תמונות |
| `images/` | כל התמונות |

## לשנות מחיר או להוסיף מאפה

הכל קורה בקובץ `products.js`. ההסבר כתוב בראש הקובץ.

- **מחיר:** משנים את `price: ''` למספר, למשל `price: 45`.
- **בשביל מה המחיר:** ממלאים את `unit`, למשל `'למגש של 12'`.
- **תיאור:** משנים את `desc`, שורה אחת קצרה.
- **תגית על התמונה:** `badge`, למשל `'הכי אהוב'`. ריק = בלי תגית.
- **מאפה חדש:** מעתיקים שורה, משנים את הפרטים, ושמים את התמונה בתיקייה `images`.
- **סדר:** הסדר ברשימה הוא הסדר באתר. הראשונים מופיעים לפני "לכל המאפים".

## ביקורות

ברשימה `REVIEWS` בקובץ `products.js`. כל עוד היא ריקה, אזור הביקורות לא מופיע.
רק ביקורות אמיתיות, במילים של הלקוח ובאישור שלו.

## הגדרות

בתחתית `products.js`, ברשימה `SITE`: מספר הוואטסאפ, כמה ימים מראש מזמינים,
ימים בלי איסוף, כמה מאפים מוצגים לפני "לכל המאפים", ואיך משלמים.

## תמונות חדשות

כדאי להקטין לפני שמעלים: רוחב של עד 1000 פיקסלים, ובערך 100-200KB לתמונה.

## לראות את האתר במחשב

לחיצה כפולה על `index.html`.

## להעלות לאוויר עם GitHub Pages

1. מעלים את התיקייה הזו ל-repository ב-GitHub.
2. ב-repository: Settings, Pages, ובוחרים את ה-branch הראשי.
3. אחרי דקה-שתיים האתר עולה בכתובת `https://<שם המשתמש>.github.io/<שם ה-repository>/`.
